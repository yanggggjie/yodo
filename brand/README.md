# yodo 品牌规范

图标、字标、颜色、字体和口号。README、宣传视频、社交平台物料都按这一份做。图标本身的设计依据见 [icon.md](icon.md)。

## 文件

| 文件 | 用途 | 来源 |
|---|---|---|
| [`icon.svg`](icon.svg) | 图标，扩展图标、头像、视频片头 | `icon.py` 生成 |
| [`wordmark-light.svg`](wordmark-light.svg) | 字标，浅色背景 | `wordmark.py` 生成 |
| [`wordmark-dark.svg`](wordmark-dark.svg) | 字标，深色背景 | `wordmark.py` 生成 |
| [`social-preview.svg`](social-preview.svg) / [`.png`](social-preview.png) | GitHub 社交预览图，1280×640 | `wordmark.py` 生成，PNG 由 `make-icons.sh` 导出 |

生成的文件不要手改。改参数后运行 `sh brand/make-icons.sh`，一次重新生成全部。

社交预览图需要在仓库 Settings → General → Social preview 里手动上传 PNG，GitHub 不会自动读取仓库里的文件。

## 口号

| 场合 | 写法 |
|---|---|
| 主口号 | **You only do once** |
| 中文 | 你只演示一次 |
| 一句话介绍 | 录制你的操作，学会其中的接口，之后直接调用接口，快！ |

- 产品名一律小写 `yodo`，句首也不大写。
- 英文口号保留英文，不翻译成中文放在同一位置；需要中文时另起一行。

## 字标

图标在左，`yodo` 在右，文字与图标等高居中。

- 文字：Inter Bold，字号为图标高度的 0.875，字距 −2（以 128 高为准）。
- 间距：图标与文字之间为图标高度的 22%。
- 留白：四周至少留出图标高度的一半。
- 最小尺寸：字标高度不小于 24 像素；更小时只用图标。
- 不要：拉伸、改字体、给文字加渐变、给图标加描边或阴影、把文字放在图标上面或下面。

## 颜色

图标的三组渐变是品牌色，其余一律用中性色。

| 名称 | 值 | 用在哪里 |
|---|---|---|
| 暮色橙红 | `#FF8A5B → #FF3D6E` | 主强调：口号、关键数字、yodo 的计时器 |
| 靛紫 | `#24166B → #6C3BE0` | 辅助：高光、转场 |
| 金橙 | `#FFC857 → #FF8A3D` | 辅助：高光、转场 |
| 墨黑 | `#0B0B10` | 深色背景；浅色背景上的文字 |
| 白 | `#FFFFFF` | 深色背景上的文字 |
| 次要灰 | `#A0A0AB` | 次要文字、地址 |
| 对照灰 | `#6B6B76` | 和其它工具对比时，对方一律用它 |

- 默认深色背景（墨黑）。浅色背景用白底和 `wordmark-light.svg`。
- 一个画面里强调色只用一处，最多两处。
- 和其它工具对比时只用灰色表示对方，不用红色，也不写贬低的话，用数据说话。

## 字体

| 用途 | 字体 |
|---|---|
| 英文、数字 | Inter（Bold 用于标题，Regular / Medium 用于正文） |
| 中文 | 苹方 / 思源黑体（Noto Sans SC），标题用 Semibold 或 Bold |
| 终端、代码、地址 | JetBrains Mono |

SVG 里的文字按上面的顺序写了备用字体，没装 Inter 的机器会用系统无衬线字体显示。

## 动效与视频

- y 的曲线就是品牌的动效：片头、转场用 `icon.py` 里同一组曲线（`A→V`、`S→V→E`）描出，再填入三块渐变。
- 快入慢出，切换卡在节拍上；数字用滚动计数。
- 录屏放在圆角窗口里，加柔和投影，背景墨黑。

## 语气

- 先说结果和数据（「56 秒」「$0.24」），再说原理。
- 短句，一屏一句。
- 说清边界：新网站要先演示一次，不承诺能自己探索。
