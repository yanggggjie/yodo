  环境

  原来那个 Chrome 用的是默认 profile 目录（~/Library/Application 
  Support/Google/Chrome），Chrome 136+ 在这种情况下会忽略 
  --remote-debugging-port，所以 9222 根本没在监听。改用独立 profile 后正常：

  "/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" \
    --remote-debugging-port=9333 \
    --user-data-dir="$HOME/temp-agent-browser-profile" \
    --no-first-run --no-default-browser-check about:blank &
  agent-browser connect 9333

  本地标准版 Chrome 151.0.7922.77，profile 在 ~/temp-agent-browser-profile/，X /
  知乎 / 即刻登录态都在里面。
